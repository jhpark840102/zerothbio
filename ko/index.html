WHY MEASURED FUNCTION

단백질 AI는 후보를 제안합니다. 기능은 여전히 측정해야 합니다.

개발 의사결정은 단백질이 정해진 조건에서 실제로 어떻게 작동하는지에 달려 있습니다. 제로스바이오는 모든 실험을 다음 설계로 이어지는 구조화된 데이터로 기록합니다.

측정 기반

실험 결과를 해석에 필요한 조건과 함께 기록합니다.

기능 중심

서열만이 아니라, 관찰된 단백질 기능의 차이를 담습니다.

반복 가능

정해진 워크플로 루프로 같은 실험을 같은 논리로 다시 수행합니다.

학습 가능

구조화된 결과는 보고서로 끝나지 않고 다음 설계 판단으로 돌아갑니다.

서열과 구조만서열 + 조건 + 측정된 기능

ProPEL · PROTEIN AI & PRECISE EXPERIMENTAL LABS

설계–제작–측정–학습, 하나의 루프

ProPEL은 단백질 설계, 실험 수행, 기능 측정과 학습을 연결합니다. 단백질 AI가 제안한 후보는 실험 결과로 검증되고, 그 결과는 다음 설계의 입력이 됩니다.

  1. 01

    DESIGN

    단백질 AI가 검증 가능한 가설과 함께 후보·변이 공간을 제안합니다.

    → 후보 세트 / 가설

  2. 02

    BUILD

    조합형 DNA 라이브러리와 무세포 단백질 합성으로, 세포 배양 없이 후보를 실제 단백질로 만듭니다.

    → 변이체 라이브러리 / 발현 단백질

  3. 03

    TEST

    기능·발현·결합·수율 분석으로 각 변이체를 정해진 조건에서 측정합니다.

    → 측정된 기능 데이터

  4. 04

    LEARN

    결과를 구조화해 다음 후보와 실험 설계에 반영합니다.

    → 구조화된 데이터셋 / 다음 설계

모든 실험은 더 나은 출발점, 다음 0번째가 됩니다.

“자율”은 ProPEL의 구조와 운영 개념을 뜻합니다. 완전 무인 운영이나 최적화 결과를 보장한다는 의미가 아니며, 과학적 검토와 판정 기준은 통제된 의사결정으로 유지됩니다.
